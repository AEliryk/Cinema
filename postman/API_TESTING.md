# 🧪 Тестирование API в Postman

**Base URL:** `http://localhost:8000`  
**Документация Swagger:** `http://localhost:8000/docs`

---

## ⚙️ Настройка Postman

1. Открой Postman → **New Collection** → назови `Movie Catalog API`
2. Для каждого запроса:
   - Вкладка **Headers** → добавь: `Content-Type: application/json`
   - Вкладка **Body** → выбери `raw` → формат `JSON`

---

## 📁 Категории (`/categories`)

### 1. Создать категорию
| Поле | Значение |
|------|----------|
| **Метод** | `POST` |
| **URL** | `http://localhost:8000/categories/` |
| **Body (raw JSON)** | см. ниже |

```json
{
  "name": "Боевик",
  "description": "Фильмы с погонями и взрывами"
}
```

**Ожидаемый ответ `201 Created`:**
```json
{
  "id": 1,
  "name": "Боевик",
  "description": "Фильмы с погонями и взрывами"
}
```

---

### 1.1. Ошибка валидации: попытка создать пустую категорию
API запрещает создание категории с пустым именем или состоящим только из пробелов.

| Поле | Значение |
|------|----------|
| **Метод** | `POST` |
| **URL** | `http://localhost:8000/categories/` |
| **Body (raw JSON)** | см. примеры ниже |

#### Вариант А: Пустая строка (`""`)
**Body:**
```json
{
  "name": "",
  "description": "Без названия"
}
```

**Ожидаемый ответ `422 Unprocessable Entity`:**
```json
{
  "detail": [
    {
      "type": "string_too_short",
      "loc": ["body", "name"],
      "msg": "String should have at least 1 character",
      "input": "",
      "ctx": {
        "min_length": 1
      }
    }
  ]
}
```

#### Вариант Б: Имя состоит только из пробелов (`"   "`)
**Body:**
```json
{
  "name": "   ",
  "description": "Только пробелы"
}
```

**Ожидаемый ответ `422 Unprocessable Entity`:**
```json
{
  "detail": [
    {
      "type": "value_error",
      "loc": ["body", "name"],
      "msg": "Value error, Название категории не может быть пустым",
      "input": "   ",
      "ctx": {
        "error": {}
      }
    }
  ]
}
```

#### Вариант В: Поле `name` вовсе не передано
**Body:**
```json
{
  "description": "Категория без поля name"
}
```

**Ожидаемый ответ `422 Unprocessable Entity`:**
```json
{
  "detail": [
    {
      "type": "missing",
      "loc": ["body", "name"],
      "msg": "Field required",
      "input": {
        "description": "Категория без поля name"
      }
    }
  ]
}
```

### 2. Получить все категории
| Поле | Значение |
|------|----------|
| **Метод** | `GET` |
| **URL** | `http://localhost:8000/categories/` |
| **Body** | не нужен |

**Query параметры (необязательно):**
| Параметр | Тип | Пример | Описание |
|----------|-----|--------|----------|
| `skip` | int | `0` | Пропустить N записей |
| `limit` | int | `10` | Вернуть не более N записей |

**Пример с параметрами:** `http://localhost:8000/categories/?skip=0&limit=10`

**Ожидаемый ответ `200 OK`:**
```json
[
  {
    "id": 1,
    "name": "Боевик",
    "description": "Фильмы с погонями и взрывами"
  }
]
```

---

### 3. Получить категорию по ID
| Поле | Значение |
|------|----------|
| **Метод** | `GET` |
| **URL** | `http://localhost:8000/categories/1` |
| **Body** | не нужен |

**Ожидаемый ответ `200 OK`:**
```json
{
  "id": 1,
  "name": "Боевик",
  "description": "Фильмы с погонями и взрывами"
}
```

**Ошибка (ID не существует) `404 Not Found`:**
```json
{
  "detail": "Категория не найдена."
}
```

---

### 4. Обновить категорию
| Поле | Значение |
|------|----------|
| **Метод** | `PUT` |
| **URL** | `http://localhost:8000/categories/1` |
| **Body (raw JSON)** | см. ниже |

```json
{
  "name": "Комедия",
  "description": "Смешные фильмы"
}
```

> 💡 Можно передавать только те поля, которые нужно обновить — остальные останутся без изменений.  
> ⚠️ **Важно:** передавать пустое имя `""` или строку из пробелов `"   "` нельзя — сервер вернёт ошибку `422 Unprocessable Entity`.

**Ожидаемый ответ `200 OK`:**
```json
{
  "id": 1,
  "name": "Комедия",
  "description": "Смешные фильмы"
}
```

---

### 5. Удалить категорию
| Поле | Значение |
|------|----------|
| **Метод** | `DELETE` |
| **URL** | `http://localhost:8000/categories/1` |
| **Body** | не нужен |

**Ожидаемый ответ `200 OK`** — возвращает удалённый объект:
```json
{
  "id": 1,
  "name": "Комедия",
  "description": "Смешные фильмы"
}
```

## 🎬 Фильмы (`/movies`)

> ⚠️ **Важно:** перед добавлением фильма нужна хотя бы одна категория в БД!  
> Используй `category_id` из созданной категории.

### 1. Создать фильм
| Поле | Значение |
|------|----------|
| **Метод** | `POST` |
| **URL** | `http://localhost:8000/movies/` |
| **Body (raw JSON)** | см. ниже |

```json
{
  "title": "Терминатор",
  "description": "Робот из будущего охотится за Джоном Коннором",
  "release_year": 1984,
  "rating": 8.1,
  "category_id": 1
}
```

**Ожидаемый ответ `201 Created`:**
```json
{
  "id": 1,
  "title": "Терминатор",
  "description": "Робот из будущего охотится за Джоном Коннором",
  "release_year": 1984,
  "rating": 8.1,
  "category_id": 1
}
```

**Ошибка (дубликат названия) `400 Bad Request`:**
```json
{
  "detail": "Фильм с таким названием уже существует, указан неверный ID категории или переданы неверные данные."
}
```

---

### 2. Получить все фильмы
| Поле | Значение |
|------|----------|
| **Метод** | `GET` |
| **URL** | `http://localhost:8000/movies/` |

| `skip` | int | `0` | Пропустить N записей |
| `limit` | int | `100` | Вернуть не более N записей |

**Фильтр по категории:** `http://localhost:8000/movies/?category_id=1`

**Ожидаемый ответ `200 OK`:**
```json
[
  {
    "id": 1,
    "title": "Терминатор",
    "description": "Робот из будущего охотится за Джоном Коннором",
    "release_year": 1984,
    "rating": 8.1,
    "category_id": 1
  }
]
```

## 📋 Рекомендуемый порядок тестирования

```
1.  GET    /                       → проверить, что сервер отвечает
2.  POST   /categories/            → создать категорию "Боевик"
3.  POST   /categories/ (пустое)   → проверить ошибку 422 при пустом имени "" или "   "
4.  POST   /categories/            → создать категорию "Комедия"
5.  GET    /categories/            → убедиться, что категории созданы
6.  GET    /categories/1           → получить одну категорию по ID
7.  PUT    /categories/1           → обновить название категории
8.  POST   /movies/                → создать фильм (category_id из шага 2)
9.  POST   /movies/                → создать ещё один фильм
10. GET    /movies/                → получить все фильмы
11. GET    /movies/?category_id=1  → фильтр по категории
12. GET    /movies/1               → фильм по ID
13. PUT    /movies/1               → обновить фильм
14. DELETE /movies/1               → удалить фильм
15. DELETE /categories/1           → удалить категорию
```

---

## ❌ Коды ошибок

| Код | Значение | Когда возникает |
|-----|----------|-----------------|
| `400` | Bad Request | Дубликат имени, неверные данные |
| `404` | Not Found | Категория или фильм не найден |
| `422` | Unprocessable Entity | Ошибка валидации: пустое имя категории, не переданы обязательные поля, неверный тип данных |
| `500` | Internal Server Error | Ошибка сервера / БД недоступна |
